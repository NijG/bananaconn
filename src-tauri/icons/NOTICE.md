# App icon

The BananaConn. mark (a peeled banana on a waffle cone) is the project's own
logo, redrawn as a vector from the logo artwork and rendered to PNG at each
icon size (source: design/bananaconn-mark.svg). The red dot on the banana tip is
drawn to scale, and its centre pixel is set to pure red (#E8302C) after each
size is rendered, so the dot shows even at 16 px.

Icons up to 0.7.28 used the Banana emoji of Microsoft Fluent Emoji (MIT
License); that artwork is no longer part of the icon.
